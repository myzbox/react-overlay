# Roadmap

Future plans and ideas for the React Modal Plugin.

## Phase 1 (Completed)
- [x] Core Modal Component
- [x] Accessible Focus Trap & Keyboard Navigation
- [x] Basic Animations (Zoom, Fade)
- [x] Alert & Confirm Variants
- [x] Formatting & Linting Setup

## Phase 2 (Completed)
- [x] Drawer Component
- [x] Draggable Modals
- [x] Tooltip Component
- [x] Theming System (CSS Variables)

## Phase 3 (Upcoming)
- [ ] **Advanced Animations**: Spring-based animations using `framer-motion` or similar.
- [ ] **Nested Modals**: Better support for stacking multiple modals.
- [ ] **Resizable Modals**: Allow users to resize dimensions via drag handles.
- [ ] **Headless Mode**: Export a headless version for complete UI control.
- [ ] **Toast Notifications**: System for non-blocking flash messages.

## Phase 4 (Long-term)
- [ ] **React Server Components (RSC)** compatibility research.
- [ ] **Global State Manager**: Optional context-based provider for opening modals imperatively.
